# Target Clicker Game 🎯

A fun and interactive desktop target-shooting game built with Python and Tkinter. Test your speed and precision across multiple difficulty settings!

---

## 🚀 Features

* **Multiple Difficulty Levels:** Choose between Easy, Medium, and Hard modes to challenge your reaction time.
* **Score & Timer Tracking:** Real-time score counter and countdown timer.
* **Control Buttons:** Easily start, restart, or toggle full-screen mode anytime.
* **Standalone Executable:** Ready-to-run `.exe` file included—no Python installation required to play!

---

## 🛠️ Built With

* **Language:** Python
* **GUI Framework:** Tkinter
* **Packaging:** PyInstaller

---

## 📥 How to Run

### Option 1: Direct Executable (No Setup Required)
1. Navigate to the `dist/` folder or download `main.exe`.
2. Double-click `main.exe` to start playing immediately!
